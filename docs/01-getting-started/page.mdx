# Getting Started

Install the package:

```sh
npm install @moyarich/workspace-tools
```

Run commands through npm scripts, `npx`, or the installed package binaries.

```sh
npx discover-packages --workspaces --json
npx workspace-dependency-check .
npx workspace-release . --mode=package-json
```

Reusable GitHub workflows are maintained separately in `moyarich/reusable-workflows`.
