# GitHub Pages workflow

Use `github-pages.yml` to build a static site and deploy it to GitHub Pages.

## Copy and paste

Create `.github/workflows/pages.yml`:

```yaml
name: GitHub Pages

on:
  push:
    branches:
      - main
  workflow_dispatch:

jobs:
  pages:
    uses: moyarich/workspace-tools/.github/workflows/reusable_github-pages.yml@v0.1.0
    with:
      build-command: npm run build
      output-directory: dist
      node-version: "24"
```

For a monorepo playground built from the repository root:

```yaml
name: GitHub Pages

on:
  push:
    branches:
      - main
  workflow_dispatch:

jobs:
  pages:
    uses: moyarich/workspace-tools/.github/workflows/reusable_github-pages.yml@v0.1.0
    with:
      build-command: npm run build:playground
      output-directory: apps/playground/dist
      node-version: "24"
```

In GitHub repository settings, configure **Settings → Pages → Build and deployment → Source** to use **GitHub Actions**.

## Base paths

During the build, the reusable workflow exposes:

```text
PAGES_BASE_PATH
PAGES_BASE_URL
PAGES_ORIGIN
```

Use `PAGES_BASE_PATH` when the site's build system needs the repository path for project Pages. The workflow itself does not assume Vite or another framework.

## Inputs

| Input               | Required | Default                     |
| ------------------- | -------- | --------------------------- |
| `build-command`     | Yes      | —                           |
| `output-directory`  | Yes      | —                           |
| `node-version`      | No       | `24`                        |
| `install-command`   | No       | `npm ci --include=optional` |
| `working-directory` | No       | `.`                         |
