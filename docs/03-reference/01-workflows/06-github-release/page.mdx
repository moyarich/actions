# Release Drafter workflow

Use `reusable_release-drafter.yml` for repositories that prepare a release draft without creating a Git tag or publishing the release.

## Copy and paste

```yaml
jobs:
  release:
    uses: moyarich/workspace-tools/.github/workflows/reusable_release-drafter.yml@v0.1.0
    permissions:
      contents: write
    with:
      target-branch: main
      version: 0.1.0
      release-name: My Project v0.1.0
      changelog-path: CHANGELOG.md
      dry-run: true
```

## Draft behavior

When no matching draft exists, the workflow creates one and seeds its body from the matching `CHANGELOG.md` entry.

When a matching draft already exists, the workflow reuses it and preserves its body so maintainer edits are not overwritten.

## Inputs

| Input            | Required | Default        |
| ---------------- | -------- | -------------- |
| `version`        | Yes      | —              |
| `release-name`   | Yes      | —              |
| `target-branch`  | No       | `main`         |
| `changelog-path` | No       | `CHANGELOG.md` |
| `dry-run`        | No       | `true`         |
