# Reference

Workspace Tools publishes command-line utilities, not reusable workflow or standalone GitHub Action definitions.

## Package structure

```text
src/                 # CLI implementations and shared workspace logic
tests/               # capability-based tests
dist/bin/            # committed executable bundles published to npm
examples/            # usage examples
docs/                # reference, guides, and development documentation
.github/workflows/   # repository-local workflow callers
```

See [Repository structure](../04-development/01-repository-structure/page.mdx) for build, test, and distribution boundaries. The reusable workflows and actions live in [moyarich/reusable-workflows](https://github.com/moyarich/reusable-workflows).
