# Moya Actions

Moya Actions is the shared automation repository for Node.js projects, npm packages, VS Code extensions, documentation sites, and other Moya repositories.

## Public automation surface

| Type | Location | Contract |
| --- | --- | --- |
| Reusable workflows | `.github/workflows/reusable_*.yml` | Public |
| Reusable actions | `actions/*/action.yml` | Public |
| Scripts and tooling | `scripts/*` | Documented reusable tooling |
| Repository workflows | `.github/workflows/*.yml` without the `reusable_` prefix | Internal |

Start with [Getting started](./01-getting-started/page.mdx) or browse the [workflow catalog](./02-workflows/page.mdx).

## Copyable examples

Consumer-ready workflow callers live under `examples/.github/workflows/`. The example tree mirrors the destination path in another repository, so the examples can be copied into `.github/workflows/` without restructuring them.

`apps/playground` may consume these repository-level examples for presentation, but the examples remain the authoritative source.
