# Workspace Tools

`@moyarich/workspace-tools` is the installable CLI/tooling package.

## Public package surface

| Capability | Commands |
| --- | --- |
| Package discovery | `discover-packages` |
| Dependency checks | `workspace-dependency-check` |
| Lockfile maintenance | `workspace-package-lock` |
| Releases | `workspace-release`, `workspace-release-identity` |
| Publishing | `workspace-publish` |
| Issue dependencies | `issue-dependency-tree` |

Reusable workflows and standalone GitHub Actions are maintained in `moyarich/reusable-workflows`.
