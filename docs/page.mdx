# Workspace Tools

`@moyarich/workspace-tools` is the installable CLI package available from [public npm](https://www.npmjs.com/package/@moyarich/workspace-tools).

## Public commands

| Capability | Commands |
| --- | --- |
| Package discovery | `discover-packages` |
| Dependency checks | `workspace-dependency-check` |
| Lockfile maintenance | `workspace-package-lock` |
| Releases | `workspace-release`, `workspace-release-identity`, `sim-version-resolver` |
| Publishing | `workspace-publish` |
| Issue dependencies | `issue-dependency-tree` |

Start with [Getting started](./01-getting-started/page.mdx) or consult the [CLI reference](./03-reference/02-workspace-cli/page.mdx).

Reusable GitHub workflows and standalone actions are maintained separately in [moyarich/reusable-workflows](https://github.com/moyarich/reusable-workflows).
