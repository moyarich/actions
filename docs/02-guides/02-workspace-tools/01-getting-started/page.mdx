# Workspace tooling

Moya Workspace Tools owns the workspace tooling used by its reusable release and publishing workflows.

The CLI surface includes:

```sh
discover-packages
workspace-dependency-check
workspace-package-lock
workspace-release-identity
workspace-release
workspace-publish
```

The commands are built into `dist/bin/` and published from the `@moyarich/workspace-tools` package. Reusable workflows resolve the matching bundled binaries from the same repository ref through the repo-local `workspace-tools` setup action.

`workspace-release` previews or creates workspace package releases. It supports version bumps, exact versions, and `package-json` mode, which releases the version already present in `package.json` without manufacturing a release-only version change.

`workspace-publish` validates and publishes workspace packages. By default, a real publish verifies that the matching package release Git tag exists and points to `HEAD`.

`workspace-dependency-check` checks external dependency freshness and internal workspace version alignment.

`workspace-package-lock` reviews or recreates the root lockfile and can optionally commit the result.

`workspace-release-identity` resolves the canonical package-scoped Git tag and GitHub Release name.

`discover-packages` uses the same package-discovery core as the standalone GitHub Action.
